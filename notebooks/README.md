# Jupyter & Kaggle Notebooks

Thư mục lưu trữ các file Notebook thực nghiệm:
- `01_eda_sample.ipynb`: Khảo sát & phân tích khám phá dữ liệu trên tệp mẫu 10k dòng.
- `02_baseline_models.ipynb`: Thực nghiệm huấn luyện các mô hình Hướng Thuần (Logistic Regression, Decision Tree, Random Forest).
- `03_sota_models.ipynb`: Thực nghiệm các mô hình cải tiến (LightGBM, CatBoost, XGBoost GPU trên Kaggle).
- `04_spark_distributed_rf.ipynb`: Huấn luyện Random Forest phân tán trên Apache Spark.
